# Parto Ativo

Landing page estática em português para o treinamento Parto Ativo, feita com HTML, CSS e JavaScript puros.

## Executar localmente

Abra `index.html` no navegador ou sirva a pasta com:

```sh
python -m http.server 8080
```

Depois acesse `http://localhost:8080`. Não há dependências nem etapa de build.

## Publicação

O projeto é implantado no Vercel a partir deste repositório GitHub. A raiz do repositório é a pasta pública; não é necessário configurar build command nem output directory.

Produção: https://partoativo.vercel.app

## Arquivos do site

- `index.html`, `styles.css`, `script.js`
- `privacidade.html` e `termos.html`
- Imagens locais do hero, seção da Samia, mockup, cards e favicon.

Os documentos legais ainda estão identificados como pendentes de validação. A landing page permanece com `noindex, nofollow` até a revisão final de conteúdo e documentação legal.
